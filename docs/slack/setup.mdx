## 1. 创建 Slack 应用

最简单的方式是使用附带的 manifest：

1. 前往 [https://api.slack.com/apps](https://api.slack.com/apps)，点击 **Create New App** > **From an app manifest**
2. 选择一个工作区
3. 粘贴 [`manifest.yaml` 模板](https://github.com/elie222/inbox-zero/blob/main/docs/slack/manifest.yaml)的内容，并把 `YOUR_DOMAIN` 替换为你的实际域名
4. 点击 **Create**

这会自动配置所有作用域、事件订阅和机器人用户。

<summary>手动设置（不使用 manifest）</summary>

### 配置 OAuth 与权限

在 **OAuth & Permissions** 下：

**重定向 URL** —— 添加：

```
https://<your-domain>/api/slack/callback
```

**机器人令牌作用域** —— 添加以下作用域：

| 作用域 | 用途 |
|-------|---------|
| `channels:read` | 解析用户在其中提及助手的公共频道 |
| `channels:join` | 在助手交互需要时加入公共频道 |
| `groups:read` | 列出可作为通知目标的私有频道 |
| `chat:write` | 发送会议简报和 AI 回复 |
| `app_mentions:read` | 响应频道中的 @提及 |
| `im:read` | 接收私信 |
| `im:write` | 发送私信回复 |
| `im:history` | 读取私信对话历史 |
| `assistant:write` | 启用 Slack 助手提示和状态指示器 |
| `reactions:write` | 添加处理中的指示表情 |
| `users:read` | 查看工作区成员 |
| `users:read.email` | 为多用户工作区按邮箱查找队友 |

### 启用事件订阅

在 **Event Subscriptions** 下：

1. 把 **Enable Events** 切换为开启
2. 把 **Request URL** 设置为：
   ```
   https://<your-domain>/api/slack/events
   ```
3. 在 **Subscribe to bot events** 下添加：
   - `message.im` —— 发送给机器人的私信
   - `app_mention` —— 频道中的 @提及
   - `assistant_thread_started` —— 初始化 Slack 助手会话提示
   - `assistant_thread_context_changed` —— 响应助手上下文切换

Slack 会向该 URL 发送一个验证挑战；应用会自动处理它。

### 启用交互

在 **Interactivity & Shortcuts** 下：

1. 把 **Interactivity** 切换为开启
2. 把 **Request URL** 设置为：
   ```
   https://<your-domain>/api/slack/events
   ```

交互操作（例如助手中的 `Send` 按钮）会发送到该 URL。没有此设置，按钮点击就无法到达应用。

### 启用应用主页

在 **App Home** 下：

1. 勾选 **Allow users to send Slash commands and messages from the messages tab**
2. 取消勾选 **Make the messages tab read-only**（如果显示）

这让用户可以直接给机器人发私信，从而与 AI 助手聊天。

## 2. 设置环境变量

从 **Basic Information** 和 **OAuth & Permissions** 页面，在你的 `.env` 中设置这些内容：

```bash
SLACK_CLIENT_ID=       # OAuth & Permissions > Client ID
SLACK_CLIENT_SECRET=   # OAuth & Permissions > Client Secret
SLACK_SIGNING_SECRET=  # Basic Information > Signing Secret
```

这三项都是可选的。如果未设置，Slack 连接按钮会被隐藏，且事件端点会返回 503。

使用 ngrok 进行本地开发时，还要设置：

```bash
WEBHOOK_URL=https://your-domain.ngrok-free.app
```

它用于 OAuth 回调和事件 webhook URL。`NEXT_PUBLIC_BASE_URL` 保持为 `http://localhost:3000`，以免影响其他认证流程。

## 3. 从 UI 连接

1. 导航到**设置** > **邮箱账号**标签页
2. 在已连接的应用下点击**连接 Slack**
3. 在 Slack OAuth 流程中授权该应用
4. 打开**渠道**，选择一个用于通知的私有 Slack 频道
5. 把 Inbox Zero 机器人邀请到该私有频道
6. 启用你想投递到那里的会议简报、跟进提醒、摘要、归档提醒或规则通知

用户也可以给机器人发私信或在频道中 @提及它，从而与 AI 助手聊天。
