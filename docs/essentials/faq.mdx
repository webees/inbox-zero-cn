关于 Inbox Zero 的常见问题解答。

### 如何向我的账号添加更多邮箱地址？

要为自己连接另一个邮箱，请打开侧边栏顶部的账号切换器，选择**添加或管理账号**。在账号页面选择**添加账号**，并连接 Gmail 或 Outlook 邮箱。你也可以打开[设置](https://www.getinboxzero.com/settings)，在邮箱账号部分选择**添加账号**。

每个已连接的邮箱都有自己的助手规则和设置。使用账号切换器在它们之间切换。

要与他人共享订阅，请改为创建或加入一个组织。在设置中，使用团队下的**邀请成员**。组织成员身份与连接另一个邮箱是两个独立的操作。

### 如何用多个分区整理我的 Gmail 收件箱？

在 Gmail 中按类型整理邮件有两种选择：

1. **使用 [Inbox Zero Tabs 扩展](/essentials/inbox-zero-tabs-extension)** —— 我们免费的浏览器扩展会为 Gmail 添加自定义标签页，让你按类型整理邮件（简报、收据、待回复等）。它与我们的 AI 助手配合得很好，AI 助手可以为这些标签页自动给邮件打标签。

   ![Inbox Zero Tabs 扩展](/images/extension.png)

2. **使用 Gmail 的多收件箱功能**：
   - 前往 Gmail 设置 → 「查看所有设置」→ 「收件箱」标签页
   - 把「收件箱类型」改为「多个收件箱」
   - 使用搜索查询创建最多 5 个分区，例如：
     - `is:starred` 表示已加星标的邮件
     - `label:Newsletter` 表示简报邮件
     - `is:unread` 表示未读邮件
     - `from:boss@company.com` 表示来自特定发件人的邮件

   ![Gmail 标签](/images/labels.png)

两种选择都能让你一眼看到不同类型的邮件，而不必滚动一长串列表。

### 如何取消订阅？

打开侧边栏底部的账号菜单，选择[设置](https://www.getinboxzero.com/settings)。在计费部分点击**管理订阅**，并在计费门户中取消。

### 如何删除我的账号？

打开侧边栏底部的账号菜单，选择[设置](https://www.getinboxzero.com/settings)。在**删除账号**部分点击**删除账号**。

### 如何撤销对我的邮箱账号的权限？

要撤销对邮箱账号的权限：

#### 对于 Gmail 账号

- 访问 Google 账号中的[关联应用](https://myaccount.google.com/u/0/connections)页面
- 搜索 **Inbox Zero**，点击它，然后点击**查看详情**
- 点击**移除所有访问权限**按钮

#### 对于 Microsoft/Outlook 账号

- 访问 Microsoft 账号中的[应用权限](https://account.microsoft.com/privacy/app-access)页面，或打开[管理应用授权](https://account.live.com/consent/Manage)
- 在列表中找到 **Inbox Zero** 并点击它
- 点击**移除**以撤销访问权限

如果你在列表中没有看到 **Inbox Zero**，说明该账号未连接到 Inbox Zero。
对于 Gmail，你可以点击右上角的个人资料图片并切换账号，以检查你的其他账号。

### 我看到错误「You have exceeded the rate limit」。如何修复？

此错误是由于邮件服务商（Gmail 和 Outlook）对每个账号都有速率限制。
如果你把自己的账号连接到了其他邮件服务，可能是它们用光了你的速率限制。

#### 对于 Gmail 账号

要查看还有哪些其他服务可以访问你的 Gmail 账号，请访问[Google 账号安全页面](https://myaccount.google.com/security)。在**你与第三方应用和服务的关联**下，点击**查看所有关联**，然后按**访问 Gmail**筛选。

#### 对于 Microsoft/Outlook 账号

访问 [Microsoft 应用权限页面](https://account.microsoft.com/privacy/app-access)，查看可以访问你的邮件和数据的应用。

如果那里有你不再使用的服务，请点击它们，然后点击**删除你与该应用的所有连接**（对于 Gmail）或**移除**（对于 Outlook）。

### 如何在 Gmail 中找到一封邮件的 message ID？

message ID 是邮件的唯一标识符。在你向支持团队报告问题时，它对我们很有帮助。

1. 在 Gmail 网页版中，点击你想查找 message ID 的邮件。
2. 在右上角，点击三点图标（竖向省略号）。
3. 点击**显示原始邮件**按钮。
4. **Message ID** 字段就是 message ID。它看起来类似这样：`<test1234567890@example.com>`。
