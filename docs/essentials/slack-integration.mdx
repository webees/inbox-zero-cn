## 连接 Slack

1. 把 Gmail 或 Outlook 账号连接到 Inbox Zero。
2. 打开左侧边栏中的**渠道**。
3. 找到 Slack 并点击**连接**。
4. 在 Slack 中批准所请求的权限。
5. 返回 Inbox Zero 后，在启用任何规则之前先为**规则通知**选择一个目的地，然后配置你想要的其他功能目的地。

已连接的工作区会带有**已连接**徽章出现在渠道页面上。

## 选择目的地

每个 Slack 功能都可以使用一条私信或一个允许的私有频道。已配置的频道投递有以下限制：

- 无法选择公共频道。
- 你必须是该私有频道的成员。
- Inbox Zero 不会自动加入所选频道。
- 如果选择器中没有某个私有频道，请使用目的地菜单中显示的 `/invite @<bot-name>` 命令邀请 Inbox Zero 机器人，然后刷新列表。

你可以为规则通知、会议简报、跟进提醒、摘要、文档归档提醒和定期的定期检查分别选择不同的目的地。

## 规则通知与草稿审阅

**规则通知**部分列出你的助手规则。首先，在该部分的页眉中选择一个目的地；如果你在未选择目的地时就启用规则，Inbox Zero 会显示「请先选择一个目标频道，然后再启用通知。」然后为 Slack 启用某条规则，并使用其菜单选择：

- **仅通知**：规则匹配时推送一条通知。
- **在聊天中起草回复**：把生成的回复投递到 Slack 以供审阅。

## 与助手聊天

- 向 Inbox Zero 机器人发送私信。
- 在机器人已被添加的 Slack 对话中 @提及它。
- 在 Slack 会话串中继续相关对话。

助手可以搜索和管理邮件、起草消息，并更新受支持的规则和设置。使用 `/help` 查看 `/summary`、`/draftreply`、`/followups` 和 `/cleanup` 等快捷命令。

## 其他 Slack 投递

从**渠道**中已连接的 Slack 部分，或从功能自身的设置中启用这些内容：

- [会议简报](/essentials/meeting-briefs)
- 跟进提醒和定期的定期检查
- [邮件摘要](/essentials/email-digest)
- [自动归档附件](/essentials/auto-file-attachments)提醒

## 断开 Slack

打开**渠道**，使用已连接 Slack 工作区旁的菜单，选择 `Disconnect Slack`。这会停止该连接的聊天访问和所有 Slack 投递。
