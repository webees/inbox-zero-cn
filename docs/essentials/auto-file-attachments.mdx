## 设置自动归档

### 连接云盘

打开左侧边栏工具下的**附件**，选择**添加 Google Drive**或**添加 OneDrive**。

对于 Google Drive，选择一个访问级别：

- **标准**：你需要为归档创建新文件夹。
- **完全访问权限**：使用你现有的文件夹。

### 选择文件夹

在 **1. 选择你的文件夹**下，在文件夹树中勾选助手可以归档到的文件夹。它只会归档到你选择的文件夹。

### 描述你的整理方式

在 **2. 描述你的整理方式**下，用一段大白话提示词覆盖你所有的归档规则，包括任何需要跳过的内容。例如：

```text
Contracts go to Transactions by property address.
Receipts go to Receipts by month.
```

如果你的提示词要求这样做，例如按月归档收据或按供应商归档发票，那么当没有合适的现有文件夹时，助手可以为文档创建新的子文件夹。

### 查看预览

选择**用我的近期邮件预览**。在 **3. 实际效果**下，助手会真实归档最多三个近期附件（不发送通知），并显示每个附件去了哪里。如果目标位置不对，请在**是否正确？**下选择 ✕ 把文件移动到正确的文件夹。满意后，选择**看起来没问题，开始自动归档**。

## 归档如何工作

当有新附件到达时，助手会把它归档到匹配的文件夹。与你的提示词不匹配的文档会被跳过。如果它不确定文件该归到哪里，它会给你发邮件询问目标位置，而不是自动归档。

## 纠正与活动

打开**附件**以查看**近期活动**并把文件移动到其他文件夹。你也可以在**允许的文件夹**下更改所选的文件夹，并在**归档规则**下编辑提示词。通知邮件会出现在来源邮件会话中，因此你也可以回复以批准归档、移动文件或撤销它。助手会从这些纠正中学习。

## 投递设置

使用附件页面上的**投递**按钮配置更新：

- **邮件确认**：文件归档完成后收到一封邮件。
- **已连接的应用**：为已连接的 Slack、Microsoft Teams 或 Telegram 账号启用文档归档提醒。在**渠道**上配置或连接它们。

对于 Slack，选择一条私信或一个允许的私有频道。所选 Slack 机器人必须已被邀请到某个私有频道，才能在那里发帖。
