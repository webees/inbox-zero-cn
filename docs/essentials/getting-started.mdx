## 1. 连接邮箱账号

在 [getinboxzero.com](https://www.getinboxzero.com) 登录并连接你的 Gmail 或 Outlook 账号。批准所请求的权限，以便 Inbox Zero 可以读取和整理邮件、创建草稿并发送邮件。

你之后可以从**设置 → 邮箱账号**添加其他邮箱。每个邮箱都有自己的规则、助手设置、分析和已连接的渠道。

<Note>
使用 Outlook？[使用 Outlook 指南](/essentials/outlook-guide)会把标签等 Gmail 术语对应到 Outlook 中的等价概念。
</Note>

## 2. 设置助手

打开侧边栏中的**助手**并完成引导式设置。Inbox Zero 会先为你提供一套智能的默认规则，把简报、营销和通知类邮件归档到一边，并为需要回复的邮件起草回复。你可以调整默认值，或用大白话描述新规则。

保存规则后：

1. 打开该规则并检查其条件和操作。
2. 使用**测试**标签页，对示例邮件或近期邮件运行它。
3. 新邮件到达后查看**历史**，了解哪些邮件被匹配以及原因。
4. 如果规则处理某封邮件不正确，请使用**修复**或[聊天](/essentials/ai-chat)。

<Tip>
先从打标签、归档或将邮件标记为已读开始。等你熟悉了规则的匹配方式后，再添加回复、转发等外发操作。
</Tip>

## 3. 清理现有邮件

使用**批量退订**找出嘈杂的发件人，使用**批量归档**按发件人分类整理较早的邮件。这些工具作用于现有邮件；助手规则则处理新到达的邮件。

在应用批量操作前，请先检查所选发件人。删除邮件比归档或标记为已读更难恢复。

## 4. 连接可选服务

- 连接日历，以获得感知空闲时间的草稿、预约链接和会议功能。
- 打开**渠道**以连接 Slack、Microsoft Teams 或 Telegram。
- Gmail 用户可以安装 Inbox Zero Tabs 浏览器扩展。
- 团队可以从**设置 → 团队**创建组织并邀请成员。

## 5. 个性化草稿

打开**助手 → 设置**来配置自动起草以及草稿的语气。详情请参阅[助手设置](/essentials/assistant-settings)。
