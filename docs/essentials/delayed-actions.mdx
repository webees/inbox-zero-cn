延迟执行让助手规则在执行操作前等待一段时间。它适用于需要暂时保持可见的邮件，或不应立即发送的邮件。

## 添加延迟

1. 打开**助手**并编辑一条规则。
2. 添加或打开一个受支持的操作。
3. 打开该操作的**更多选项**菜单，选择**添加延迟**。
4. 设置 1 分钟到 90 天之间的延迟，然后保存规则。

延迟属于该特定操作。同一条规则中的其他操作仍可立即运行，或使用不同的延迟。

## 支持的操作

你可以延迟执行：

- 归档
- 打标签
- 发送回复
- 发送邮件
- 转发
- 标记为已读
- 加星标
- 删除
- 移动到文件夹

其他操作无法延迟。

## 常见用途

- 七天后再归档简报邮件。
- 短暂延迟后发送自动回复。
- 时效性通知过期后将其从收件箱中移除。
- 在审阅窗口结束后把较早的邮件移动到某个文件夹。
