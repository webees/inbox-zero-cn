Inbox Zero 全面支持 Outlook，包括 Microsoft 365 工作或学校账号以及个人 Outlook 账号。连接方式与 Gmail 相同：遵循[开始使用指南](/essentials/getting-started)，在连接时选择 Outlook，并批准所请求的 Microsoft 权限。

主文档中的所有内容都适用于两个服务商。本页面涵盖少量 Outlook 特有的内容。

<Note>
在受管理的 Microsoft 365 租户上，组织管理员可能需要先批准该应用，你的账号才能连接。如果之后在 Microsoft 中撤销了访问权限，请从 Inbox Zero 重新连接该邮箱。
</Note>

## Outlook 中的 Gmail 术语

Inbox Zero 的一些视频和截图是用 Gmail 录制的。步骤在 Outlook 中相同，只是邮件概念不同：

| Gmail 术语 | Outlook 对应概念 |
| --- | --- |
| 标签 | 类别 |
| 移动到标签 | 移动到文件夹 |
| 归档 | 存档文件夹 |
| 回收站 | 已删除邮件 |
| 垃圾邮件 | 垃圾邮件 |
| Google 日历 | Outlook 日历 |
| Google Drive | OneDrive 或 SharePoint |

## Tabs 扩展

[Inbox Zero Tabs](/essentials/inbox-zero-tabs-extension) 浏览器扩展是唯一仅适用于 Gmail 的功能。Outlook 原生就包含类似的收件箱整理工具，例如文件夹、类别和重点收件箱，因此该扩展专门面向 Gmail。

一些[抢先体验](/essentials/deep-clean)实验也可能先在一个服务商上线，再在另一个上线。

## Shared mailboxes

Inbox Zero connects the mailbox of the Microsoft account you sign in with. Shared mailboxes that you access through your own account are not supported, and they will not appear after connecting.

To use Inbox Zero on a shared mailbox, a Microsoft 365 administrator can [convert it to a regular user mailbox](https://learn.microsoft.com/en-us/microsoft-365/admin/email/convert-user-mailbox-to-shared-mailbox#convert-a-shared-mailbox-back-to-a-users-mailbox), which requires assigning it a license. You can then connect it to Inbox Zero as its own account by signing in with that mailbox's address.

## Outlook troubleshooting

### Microsoft 不授权该连接

用预期的 Microsoft 账号重试。对于受管理的 Microsoft 365 租户，请询问管理员用户同意是否受限制，或 Inbox Zero 应用是否需要审批。

### 规则使用了错误的类别或文件夹

确认该类别或文件夹在已连接的 Outlook 邮箱中仍然存在，然后编辑并重新测试该规则。设置和规则不会在各已连接邮箱之间自动共享。

### Inbox Zero 停止接收 Outlook 邮件

打开**设置 → 邮箱账号**，如果该 Outlook 账号显示权限或订阅错误，请重新连接它。你也可以从 [Microsoft 应用权限页面](https://account.microsoft.com/privacy/app-access)查看或撤销 Inbox Zero。
