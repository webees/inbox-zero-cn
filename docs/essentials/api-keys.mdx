Inbox Zero 默认承担 AI 费用，但你也可以选择使用自己的模型服务商 API 密钥。

<Note>
此设置针对为 Inbox Zero 功能提供支持的 AI 服务商。它不同于**开发者**设置部分中的开发者 API 密钥，后者用于对 Inbox Zero API 的请求进行认证。
</Note>

## 配置服务商

1. 打开侧边栏底部的账号菜单，选择**设置**。
2. 展开相关的邮箱账号。
3. 找到 **AI 模型**部分。
4. 选择服务商，输入服务商的模型标识符和 API 密钥，然后点击**保存**。
5. 在**助手**或**聊天**页面测试该配置。

把服务商保持为**默认**即可使用 Inbox Zero 自带的 AI 服务。

## 设置中的服务商

### Anthropic

在 [Anthropic Console](https://console.anthropic.com/settings/keys) 创建一个密钥。在模型字段中输入 Anthropic 模型标识符。

### OpenAI

在 [OpenAI API keys 页面](https://platform.openai.com/api-keys)创建一个密钥。

### Azure OpenAI

使用 Azure OpenAI API 密钥，并在模型字段中输入 Azure 部署名称。

### Google

在 [Google AI Studio](https://aistudio.google.com/app/apikey) 创建 Gemini API 密钥，并输入对应的模型标识符。

### Groq

在 [Groq Console](https://console.groq.com/keys) 创建一个密钥，并输入你的 Groq 账号可用的模型。

### Cerebras

在 [Cerebras Cloud Console](https://cloud.cerebras.ai) 创建一个密钥，并输入诸如 `qwen-3.8-27b` 的 Cerebras 模型 ID。

### OpenRouter

在 [OpenRouter](https://openrouter.ai/settings/keys) 创建一个密钥。使用 OpenRouter 带服务商限定的模型标识符，例如 `provider/model`。

### Vercel AI Gateway

在 Vercel 创建 AI Gateway API 密钥，并使用 [Vercel AI Gateway](https://vercel.com/ai-gateway) 所期望的模型标识符。推荐使用带服务商限定的标识符。

## 用量与计费

当你使用自己的服务商密钥时，由该服务商根据其定价和限额向该账号计费。点击 AI 模型部分中的**查看用量**以查看 Inbox Zero 记录的用量。服务商侧的计费仍是费用的最终依据。
