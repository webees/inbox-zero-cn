Inbox Zero 提供 iOS 和 Android 版本。移动应用使用与你在网页端相同的 Inbox Zero 账号以及已连接的 Gmail 或 Outlook 账号。

## 安装并登录

1. 打开 [getinboxzero.com/app](https://www.getinboxzero.com/app)。
2. 选择 **App Store** 或 **Google Play**。
3. 安装 Inbox Zero，并用你现有的账号登录。如果你是新用户，请创建一个账号，并在设置过程中连接 Gmail 或 Outlook。

这些应用可以免费下载。在网页端需要付费 Inbox Zero 套餐的功能，在移动端也保持相同的套餐要求。

## 你能做什么

当前的移动端体验支持核心的收件箱和助手工作流，包括：

- 与 AI 助手聊天，询问邮件、获取摘要并准备回复。
- 阅读会话，并发送新邮件或回复。
- 查看需要回复的邮件，以及简报、促销和通知等常见类别。
- 在合并收件箱视图中跨你已连接的收件箱操作。
- 对单个或选中的会话执行归档、恢复、移至回收站，或撤销这些操作。
- 用大白话提示词创建规则或手动配置规则，然后编辑、启用、停用或删除规则。

某些账号管理和高级配置在网页应用中仍然更便捷，或仅在网页应用中提供。如果移动端没有某个设置，请在桌面浏览器中打开 Inbox Zero。

## 多个收件箱

合并收件箱会显示来自每个已连接邮箱账号的邮件。

## 故障排查

### 登录时返回浏览器而不是应用

更新应用，并从其登录页面重试。如果回调仍未返回，请关闭浏览器标签页，重新打开应用，并重新开始一次登录。

### 某个已连接的账号是空的

在网页端打开该账号，确认其 Gmail 或 Outlook 连接有效。然后刷新移动端视图。

### 移动端缺少某个网页功能

完整的设置和管理界面请使用网页应用。移动端和网页端共用同一个账号，因此在网页端保存的更改会在移动端生效。
