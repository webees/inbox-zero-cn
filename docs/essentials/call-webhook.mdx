**调用 webhook** 规则操作会在邮件匹配规则时向外部服务发送一个 JSON 请求。

## 配置该操作

1. 打开**助手**并编辑一条规则。
2. 添加**调用 webhook** 操作。
3. 输入一个可公开访问的 HTTP 或 HTTPS 端点。
4. 保存规则。

Inbox Zero 会校验 webhook 目标，并拒绝不安全或私有网络地址。

## 请求契约

- **方法：** `POST`
- **Content-Type：** `application/json`
- **认证头：** `X-Webhook-Secret`
- **成功响应：** 任意 `2xx` 状态码
- **超时：** 1 秒

Inbox Zero 不会等待或解析响应体。超时、被拦截的目标、网络故障或非 `2xx` 响应会被记录，但不会阻止其余规则操作。Webhook 调用不会重试，因此端点应快速确认，并把耗时更长的工作异步排队。

## 负载

```typescript
{
  email: {
    threadId: string;
    messageId: string;
    subject: string;
    from: string;
    cc?: string;
    bcc?: string;
    headerMessageId: string;
  };
  executedRule: {
    id: string;
    ruleId: string | null;
    reason: string | null;
    automated: boolean;
    createdAt: string;
  };
}
```

`threadId` 和 `messageId` 是服务商特定的 Gmail 或 Outlook 标识符。`createdAt` 是 ISO 8601 时间戳。如果原始规则已不存在，`ruleId` 可能为 `null`。

## Webhook 密钥

打开**设置**，找到**开发者**部分，生成一个 Webhook 密钥。该密钥仅在生成时显示，因此请在关闭对话框前复制它。重新生成会立即改变未来请求所发送的值。

每个请求都包含 `X-Webhook-Secret` 头。你的端点应在处理负载前把该头与存储的密钥进行比较。
