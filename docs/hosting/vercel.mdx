本指南介绍使用 Neon 和 Upstash 集成在 Vercel 上进行托管部署。
如需使用其他数据库，请参阅[环境变量](/hosting/environment-variables)了解更多详情。

## 1. 使用 CLI 的快捷方式

如果你已安装 Inbox Zero CLI，最快的方式是：

```bash
inbox-zero setup-vercel
```

该命令会：

- 将 `apps/web` 链接到一个 Vercel 项目
- 通过 Vercel Marketplace 集成预配 Neon 和 Upstash Redis
- 生成所需的应用密钥
- 写入 Vercel 环境变量
- （可选）触发 `vercel deploy --prod`

如果你已预配其中一个集成，请使用 `--skip-neon` 或 `--skip-upstash` 重新运行。

## 2. 手动在 Vercel 上部署

点击此处部署到 Vercel：

[![部署到 Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Felie222%2Finbox-zero&root-directory=apps%2Fweb&env=AUTH_SECRET%2CINTERNAL_API_KEY%2CEMAIL_ENCRYPT_SECRET%2CEMAIL_ENCRYPT_SALT%2CMICROSOFT_WEBHOOK_CLIENT_STATE%2CDEFAULT_LLMS%2CLLM_API_KEY)

<Warning>
  部署按钮只会预填下面列出的密钥。在你附加 Postgres 数据库并存在 `DATABASE_URL` 之前，
  首次 Vercel 构建通常会失败。
  这是预期情况。请从 Vercel Storage 创建一个免费的 Neon 数据库，然后重新部署。
</Warning>

设置以下环境变量：

```bash
AUTH_SECRET= # https://generate-secret.vercel.app/32
INTERNAL_API_KEY= # https://generate-secret.vercel.app/32
EMAIL_ENCRYPT_SECRET= # https://generate-secret.vercel.app/32
EMAIL_ENCRYPT_SALT= # https://generate-secret.vercel.app/16
MICROSOFT_WEBHOOK_CLIENT_STATE= # https://generate-secret.vercel.app/32

# LLM:
DEFAULT_LLMS= # provider:model, e.g. openai:gpt-6-luna
LLM_API_KEY=
```

在 macOS 或 Linux 上，你也可以使用 `openssl rand -base64 32` 生成密钥。

要获取你的 LLM API 密钥，请参阅 [LLM 设置](/hosting/llm-setup)。

<Tip>
  完整的环境变量列表请参阅[环境变量](/hosting/environment-variables)。我们会在本指南后面设置更多环境变量。
</Tip>

## 3. 在 Vercel 中创建 Neon PostgreSQL 数据库

Neon 是一个 PostgreSQL 数据库服务商，其免费套餐足以满足个人使用场景。

1. 在你的 Vercel 项目中，打开 `Storage`。
2. 点击 `Create Database`。
3. 点击 `Neon`。

Vercel 会自动注入 Neon 连接变量。

连接 Neon 后，Vercel 会添加 `DATABASE_URL`。完成这个初次设置后请重新部署。

![Vercel Storage 中的 Neon 选项。](/images/self-hosting/vercel/neon.png)

## 4. 在 Vercel 中创建 Upstash Redis 数据库

Upstash 是一个 Redis 数据库服务商，其免费套餐足以满足个人使用场景。

1. 在你的 Vercel 项目中，打开 `Storage`。
2. 点击 `Create Database`。
3. 点击 `Upstash`。

Vercel 会自动注入 Upstash 连接变量。

## 5. 设置其他环境变量

当 Vercel 分配你的项目域名后（例如 `https://your-project.vercel.app`），设置：

前往项目 `Settings` -> `Environment Variables` 并添加：

```bash
NEXT_PUBLIC_BASE_URL=https://your-project.vercel.app
```

根据指南设置 Google 或 Microsoft 环境变量：

- [Google OAuth](/hosting/google-oauth)
- [Microsoft OAuth](/hosting/microsoft-oauth)
- [Google PubSub](/hosting/google-pubsub)

## 6. 重新部署并验证

1. 触发一次新的 Vercel 部署。
2. 确认构建完成。
3. 访问你的项目域名并验证其正常工作。
4. 登录并连接一个邮箱账号。
