---
title: 'Microsoft OAuth'
description: '配置 Azure 应用注册和 Microsoft Graph 权限'
---

前往 [Microsoft Azure Portal](https://portal.azure.com/)并创建一个新的应用注册：

1. 导航到 Microsoft Entra ID > 「应用注册」> 「新注册」。
2. 选择一个名称并选择支持的账号类型：
   - **多租户**（默认）：允许任何 Microsoft 账号
   - **单租户**：限制为你的组织
3. 设置重定向 URI：
   - 平台：Web
   - URL：`http://localhost:3000/api/auth/callback/microsoft`（生产环境请替换为你的域名）
4. 点击「注册」。
5. 在「身份验证」中，添加额外的重定向 URI（生产环境请把 `localhost:3000` 替换为你的域名）：
   - `http://localhost:3000/api/outlook/linking/callback`
   - `http://localhost:3000/api/outlook/calendar/callback`（可选）
   - `http://localhost:3000/api/outlook/drive/callback`（可选）

6. **获取凭据**，来自「概述」标签页：
   - 复制「应用程序(客户端) ID」→ `MICROSOFT_CLIENT_ID`
   - 对于单租户，复制「目录(租户) ID」→ `MICROSOFT_TENANT_ID`
   - 前往「证书和密码」>「新客户端密码」> 复制**值** → `MICROSOFT_CLIENT_SECRET`

7. **配置 API 权限：**
   - 前往「API 权限」>「添加权限」>「Microsoft Graph」>「委托的权限」
   - 添加：`openid`、`profile`、`email`、`User.Read`、`offline_access`、`Mail.ReadWrite`、`Mail.Send`、`MailboxSettings.ReadWrite`、`Calendars.Read`、`Calendars.ReadWrite`、`Files.ReadWrite`
   - 如果 `NEXT_PUBLIC_CONTACTS_ENABLED=true`，还要添加 `Contacts.Read`（已保存的联系人）和 `People.Read`（目录和近期往来对象），以便在撰写时提供联系人建议。
   - 已有账号即使没有这两个权限也可以继续使用核心邮件功能，建议仍会基于该账号已授予的任一权限工作。撰写框会提供一个可选的重新连接操作以授予这两者。
   - 如果你是管理员，请点击「授予管理员同意」。
