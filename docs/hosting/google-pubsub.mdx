title: 'Google PubSub'
description: '使用 Google PubSub 配置 Gmail 推送通知'
---

<Tip>
  **自动化设置：** 如果你运行了 `inbox-zero setup-google`，Pub/Sub 主题和订阅已自动创建。请跳到下文的「本地开发」部分。
</Tip>

请先完成 [Google OAuth](/hosting/google-oauth)。

PubSub 启用实时邮件通知，使 Inbox Zero 在新邮件到达时立即得到通知。

### 1. 创建主题

1. 前往 Google Cloud Console 中的 [Pub/Sub 主题页面](https://console.cloud.google.com/cloudpubsub/topic/list)。
2. 点击**创建主题**。
3. 输入主题 ID（例如 `inbox-zero-emails`）。
4. 点击**创建**。

### 2. 授予 Gmail 发布访问权限

Gmail 需要权限才能向你的主题发送通知。这一步让 Google 的服务器可以把邮件事件推送到你的 Pub/Sub 主题。

1. 点击你的主题名称以打开它。
2. 前往**权限**标签页（你可能会看到它标为右侧的「信息面板」—— 寻找「权限」部分）。
3. 点击**添加主账号**。
4. 在「新主账号」字段中，输入：`gmail-api-push@system.gserviceaccount.com`
5. 在「角色」下拉菜单中，选择 **Pub/Sub 发布者**。
6. 点击**保存**。

<Info>
  `gmail-api-push@system.gserviceaccount.com` 是 Google 用于发送 Gmail 推送通知的服务账号。这不是你的账号 —— 它是 Gmail API 使用的、由 Google 管理的服务账号。更多详情请参阅[官方文档](https://developers.google.com/gmail/api/guides/push#grant_publish_rights_on_your_topic)。
</Info>

### 3. 创建推送订阅

1. 在你的主题中，前往**订阅**标签页。
2. 点击**创建订阅**。
3. 把**投递类型**设为**推送**。
4. 把**端点 URL**设为：`https://yourdomain.com/api/google/webhook?token=TOKEN`
5. 点击**创建**。

### 4. 更新你的环境变量

在你的 `.env` 文件中设置以下内容：
- `GOOGLE_PUBSUB_TOPIC_NAME` —— 完整的主题名称（例如 `projects/your-project-id/topics/inbox-zero-emails`）
- `GOOGLE_PUBSUB_VERIFICATION_TOKEN` —— 你在上面 webhook URL 中使用的 `TOKEN` 值

如果你的部署用上游认证保护 `/api/google/webhook`，可以把 `GOOGLE_PUBSUB_VERIFICATION_TOKEN` 设为空字符串，以有意禁用查询参数验证。不设置它会被视为配置错误。

### 本地开发

使用 ngrok 暴露你的本地服务器：

```bash
ngrok http 3000
```

然后在 [Google PubSub 订阅仪表板](https://console.cloud.google.com/cloudpubsub/subscription/list)中把 webhook 端点更新为你的 ngrok URL（例如 `https://abc123.ngrok.io/api/google/webhook?token=TOKEN`）。
