title: '快速开始'
description: '在 5 分钟内自托管 Inbox Zero'
---

自托管 Inbox Zero 最快的方式是用两条命令：

```bash
npx @inbox-zero/cli setup      # One-time setup wizard
npx @inbox-zero/cli start      # Start containers
```

然后打开 [http://localhost:3000](http://localhost:3000)（或你的域名）。

<Info>
  **前置要求：** 必须安装 [Docker](https://docs.docker.com/engine/install/) 和 [Node.js](https://nodejs.org/) v24+。
</Info>

CLI 会引导你配置 [Google OAuth](/hosting/google-oauth) 或 [Microsoft OAuth](/hosting/microsoft-oauth) 以及你的 AI 服务商。手动配置请参阅[设置指南](/hosting/setup-guides)。

<Info>
  **CLI 是可选的：** setup 命令是一个便捷封装，它帮助你准备 `.env`，并以合理的默认值运行 Docker Compose。

  更喜欢手动设置？克隆仓库，把 `apps/web/.env.example` 复制为 `apps/web/.env`，然后用 `ln -s apps/web/.env .env` 为 Compose 链接它一次，再运行与你的环境匹配的 Docker/Node 命令。
</Info>

在 Windows 上，请在 PowerShell 中运行 CLI 打印出的 Docker 命令。这些指南中的手动 shell 示例使用 POSIX 语法（Windows 上的 Git Bash 或 WSL）。

## 安装方式

除了使用 `npx`，你也可以全局安装 CLI：

<CodeGroup>

```bash npm
npm install -g @inbox-zero/cli
inbox-zero setup
inbox-zero start
```

```bash Homebrew
brew install inbox-zero/inbox-zero/inbox-zero
inbox-zero setup
inbox-zero start
```

</CodeGroup>

## CLI 命令参考

| 命令 | 说明 |
|---------|-------------|
| `inbox-zero setup` | 一次性设置向导 |
| `inbox-zero start` | 启动容器 |
| `inbox-zero stop` | 停止容器 |
| `inbox-zero update` | 拉取最新镜像并重启 |
| `inbox-zero logs -f` | 跟踪容器日志 |
| `inbox-zero status` | 显示容器状态 |
| `inbox-zero config` | 交互式配置编辑器 |
| `inbox-zero config set <key> <value>` | 设置一个配置值 |
| `inbox-zero config get <key>` | 获取一个配置值 |
| `inbox-zero setup-google` | 使用 `gcloud` 配置 Google API、OAuth 指引和 Pub/Sub |
| `inbox-zero setup-aws` | 使用 Copilot（ECS/Fargate）部署到 AWS |
| `inbox-zero setup-terraform` | 为 AWS 部署生成 Terraform 文件 |
| `inbox-zero setup-vercel` | 关联 Vercel、预配可选的 Neon/Upstash 资源并写入环境变量 |

运行 `inbox-zero <command> --help` 查看具体命令的选项。部署命令也在 [Google OAuth](/hosting/google-oauth)、[AWS](/hosting/aws) 和 [Vercel](/hosting/vercel) 指南中有所介绍。

## 更新

要更新到最新版本：

```bash
inbox-zero update
```

或使用 Docker Compose 手动操作：

```bash
docker compose pull web
NEXT_PUBLIC_BASE_URL=https://yourdomain.com docker compose --profile all up -d
```

## 卸载 / 重新开始

需要移除 Inbox Zero 或重新开始？请参阅故障排查中的[完整清理指南](/hosting/troubleshooting#uninstalling--starting-over)。
