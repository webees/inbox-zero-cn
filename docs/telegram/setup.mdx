---
title: "Telegram 集成设置"
description: "为 Inbox Zero 助手聊天设置 Telegram 机器人。"
---

本指南面向希望启用与 Inbox Zero 助手进行 Telegram 聊天的自托管部署。

## 1. 使用 BotFather 创建 Telegram 机器人

1. 打开 Telegram，与 [@BotFather](https://t.me/BotFather) 开始聊天
2. 发送 `/newbot`
3. 选择显示名称和机器人用户名（必须以 `bot` 结尾）
4. 复制 BotFather 返回的机器人令牌 —— 这就是你的 `TELEGRAM_BOT_TOKEN`

## 2. 配置 webhook

把你的机器人 webhook 设置为 Inbox Zero：

```bash
curl -X POST "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook" \
  -d "url=https://<your-domain>/api/telegram/events" \
  -d "secret_token=<TELEGRAM_BOT_SECRET_TOKEN>"
```

你可以用以下命令验证 webhook 状态：

```bash
curl "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/getWebhookInfo"
```

## 3. 设置环境变量

在 `apps/web/.env`（或你的部署环境）中设置这些内容：

```bash
TELEGRAM_BOT_TOKEN=
TELEGRAM_BOT_SECRET_TOKEN=
```

如果缺少 `TELEGRAM_BOT_TOKEN`，UI 中会隐藏 Telegram 连接选项，且 `/api/telegram/events` 会返回 `503`。

只要设置了 `TELEGRAM_BOT_TOKEN`，就必须设置 `TELEGRAM_BOT_SECRET_TOKEN`。如果缺少它，部署会在启动校验时失败。Telegram 会在 `x-telegram-bot-api-secret-token` 中发送该值；缺少或不匹配该值的请求会被拒绝。

## 4. 配置机器人命令和可选的个人资料照片（一次性）

配置好环境后，运行一次设置脚本：

```bash
pnpm --filter inbox-zero-ai exec tsx scripts/setup-telegram-bot.ts
```

本地快捷方式：

```bash
pnpm --filter inbox-zero-ai telegram:setup
```

若要同时设置机器人个人资料照片：

```bash
pnpm --filter inbox-zero-ai exec tsx scripts/setup-telegram-bot.ts \
  --profile-photo-url https://<your-domain>/telegram-bot.png
```

此命令会注册 Telegram 斜杠命令（`/connect`、`/switch`、`/help`、`/cleanup`、`/summary`、`/draftreply`、`/followups`），并且仅在机器人还没有个人资料照片时才设置一张。

## 5. 从 Inbox Zero 连接用户账号

每个 Inbox Zero 邮箱账号都通过一个连接码关联到一个 Telegram 用户：

1. 在 Inbox Zero 中，前往**设置** → **已连接的应用**
2. 点击**连接 Telegram**
3. 复制生成的命令：`/connect <code>`
4. 在 Telegram 中打开与你的机器人的私信
5. 发送该命令

关联后，该用户就可以在该私信中与助手聊天。

## 6. 端到端验证

检查：

1. 对于有效的 Telegram 更新，`POST /api/telegram/events` 返回 `200`
2. 在机器人私信中发送 `/connect <code>` 能关联账号
3. 一条普通的私信消息能得到助手回复

如果关联失败，请生成一个新验证码 —— 验证码是一次性的，并在 10 分钟后过期。

对于本地开发，Telegram 必须能访问一个公开的 HTTPS URL（例如通过 ngrok）；Telegram 无法访问 `localhost`。
