<Update label="October 30, 2026" description="Copy Verification Codes">
  收件箱里的验证码会以按钮形式显示，点击即可复制验证码，无需打开邮件。

  - 手机上的通知里也会包含验证码
  - 加星标、标记为已读或添加标签后，改动会立即生效
  - 会议简报会跳过你拒绝的会议，也不会包含已拒绝的参会人
</Update>

<Update label="October 22, 2026" description="Mail and Assistant">
  邮件和助手并排位于任一侧边栏的顶部，你可以在同一处切换收件箱和助手。在手机上，从邮件工具栏打开导航。

  - 打印邮件或整个会话。下载邮件，或打开原始源码进行复制或保存
  - 从会话菜单中，为最近给你写信的人启动一条已预填好的规则
  - 空收件箱会显示日出图案和"你已达成 inbox zero"。清空的分类会显示"全部清空"
  - 设置位于邮件侧边栏底部，就在你的账号上方
</Update>

<Update label="October 21, 2026" description="Reply All">
  将鼠标悬停在发送给其他人的邮件上，回复和转发旁边会显示全部回复。它会发送给发件人并抄送其他收件人，但不会包含你自己。

  - 拖动分类标签可重新排列收件箱。重新加载后，新顺序仍会保留
  - 邮件末尾的 URL 会以链接形式发送，你打开的邮件中的裸 URL 和电子邮件地址也可以点击
  - 在打开的会话中，Cmd/Ctrl+A 会选中所有邮件，让你可以把整个会话复制为文本
  - 选中一段文字并按 Enter，即可带着该文字的引用进行回复
  - 手机上的回复通知会包含简短的邮件预览
</Update>

<Update label="October 20, 2026" description="Check Before You Send">
  邮件发出前，如果你提到了某个附件却没有添加，或在正文中留下了 [company name] 这样的占位符，你会收到提醒。你可以返回修改，或仍然发送。

  - 检查会查看你写的内容，但不会检查引用的会话和你的签名
  - 分栏视图在所有账号中可用，并沿用你已保存的布局
  - 当你的账号属于某个组织时，讨论区会显示在侧边栏中，并带有未读计数
</Update>

<Update label="October 19, 2026" description="Drafts from Your Docs">
  回复草稿在撰写前可以查找你的公开文档。在草稿知识库中添加文档站点，当回复需要其中的答案时，助手会使用这些页面。

  - 打开助手设置，然后进入草稿知识库，添加站点
  - 只会读取你添加的 URL 下的公开页面
  - 你可以添加一个站点，Plus 套餐最多可添加五个
</Update>

<Update label="October 16, 2026" description="A Free Email App">
  你可以在网页、桌面和 iPhone 上免费使用 Inbox Zero 收发邮件，只在需要时才添加 AI 助手。

  - 注册时选择 AI 助手、邮件应用或两者都要。选择邮件应用会直接打开收件箱，跳过 AI 设置
  - 如果你只需要邮件应用，升级页面允许你免费继续
  - 收件箱会保留在侧边栏中，因此你可以在 Inbox Zero 的其他页面打开应用
  - 在桌面应用中，从账号菜单打开设置，或按 Cmd/Ctrl+,
</Update>

<Update label="October 14, 2026" description="从正确的地址回复">
  当有人写信给你某个可用于发送的 Gmail 地址时，你的回复现在会从该地址发出，而不是默认地址。

  - 当你可以从多个地址发送时，会出现"发件人"选择器，新邮件中也有
  - 切换地址会带入该地址的 Gmail 签名，且不会改动你写的内容
  - AI 草稿和自动回复也会使用匹配的地址
  - 发送新邮件后，确认提示提供"查看"，让你无需离开当前位置即可打开
</Update>

<Update label="October 10, 2026" description="待回复提醒">
  当新邮件进入待回复时，你会在手机上收到推送，无需打开应用就能知道哪些邮件需要关注。

  - 应用未获得焦点时，桌面端的新邮件通知已恢复
  - 定时发送和撤销发送中的邮件不再让草稿停留在草稿箱
  - 撤销发送现在只有更短的 10 秒窗口
</Update>

<Update label="October 9, 2026" description="更丰富的撰写编辑">
  撰写器现在编辑的是真实的邮件 HTML，因此包含表格、样式块和托管徽标的签名在撰写和发送时都能保持原样，而不会被压平或锁定为只读块。

  - 收件人建议会从你设备上已有的邮件中提取，即使没有 Google 通讯录访问权限也可以使用
  - Slack 确认卡片会显示完整的待发草稿（而不是截断的预览），超长邮件的"发送"位于最后一张卡片上
  - 助手回复会跟随你所回复邮件的语言，而不是你聊天时使用的语言，除非你另有要求
  - 延迟、移入垃圾箱、标记为垃圾邮件或移动后，阅读器会像归档后一样前进到下一个会话
</Update>

<Update label="October 8, 2026" description="内联团队评论">
  团队评论现在位于会话中。按 M（或从更多操作 / 命令 K）打开，在邮件下方进行内联讨论，并通过 @ 提及队友来与其共享会话。

  - 未共享的会话保持安静：只有在你打开后才会显示评论，且仅当你的组织中有队友时可用
  - 当你发送时，@ 提及不在会话中的人会与其共享该会话
  - 回复草稿会同步到你的邮箱，因此会显示在 Gmail、Outlook 和你的其他设备上
  - "与我共享"和动态位于你的账号菜单中，这些页面上的会话 / 动态标签页更加清晰
</Update>

<Update label="October 7, 2026" description="翻译会话">
  打开外语会话并点击翻译，Inbox Zero 会按需将邮件转换为你使用的语言。在你请求之前不会执行任何操作，因此你可以掌控 AI 何时读取邮件。

  - 从阅读器的更多菜单、命令面板（Cmd+K）或 Shift+T 进行翻译
  - 每条已翻译的邮件会显示其原始语言，并可通过"显示原文"切换回去
  - 已是你所用语言的邮件保持原样；再次翻译会切回原文，而不会再次调用 AI
  - 如果连接在回答中途断开，聊天回复会恢复；"停止"现在会真正取消运行
</Update>

<Update label="October 6, 2026" description="批量退订侧边面板">
  现在点击发件人时，批量退订会打开一个侧边面板，无需离开页面即可查看统计、其邮件和阅读器。更清晰的状态和触手可及的操作让你更快清理列表。

  - 状态分为待审核、所有发件人、已退订、已自动归档和已保留；待审核会隐藏没有退订链接的发件人，除非你将其包含在内
  - 如果你只想停止接收未来的邮件而不处理现有会话，请关闭"退订时归档"
  - 退订、保留和归档位于页面底部的浮动栏中
  - 很少阅读的发件人邮件与每周摘要的外观一致，其中的行可直接链接到批量退订
</Update>

<Update label="October 3, 2026" description="附件预览">
  点击会话中的图片或 PDF 附件即可直接在 Inbox Zero 中打开，无需下载。快速浏览文件后，如需副本可从对话框中下载。

  - 支持常见图片格式和 PDF
  - 现在，你的账号时区会决定会议简报、可用时间和预约链接，日历设置中提供了可搜索的城市选择器
  - 在批量退订中，滚动较长的发件人列表时表头会保持固定
</Update>

<Update label="September 28, 2026" description="连接常用应用">
  HubSpot、Salesforce、Slack 以及其他你已经在使用的应用现在可通过其自身的登录方式连接，无需先拥有 Pipedream 账号。连接后，助手可以在你撰写和整理邮件时在这些应用中查找信息。

  - 开箱即可使用 11 个应用：HubSpot、Salesforce、Airtable、Google Sheets、Slack、Asana、ClickUp、Jira、Zendesk、QuickBooks 和 Calendly
  - 每个连接都使用该应用自己的 OAuth 页面
  - 工具经过精选且为只读，因此助手可以查找信息而不会更改你的数据
  - 集成列表更加简洁，只显示应用名称
</Update>

<Update label="September 27, 2026" description="撤销发送">
  误点了发送？你的邮件会保留 30 秒以便撤销，即使你关闭标签页或退出应用也一样。从提示中撤销，草稿即可恢复。

  - 关闭标签页或退出应用不再会提前结束撤销窗口
  - 发送回复后，会话会跳转到你已发送的邮件，方便你继续阅读
  - HubSpot、Salesforce、Slack 和 Airtable 等常用应用现在会在集成页面上单独显示为一行
</Update>

<Update label="September 26, 2026" description="弹出式回复">
  将回复从会话中弹出到独立窗口，让你在撰写时继续浏览其他邮件。使用"草稿发至…"旁边的按钮，或按 Cmd+Shift+P。

  - 支持回复、转发和已保存的草稿，你的文本、收件人、附件和发送时间都会一并带过来
  - 关闭窗口后草稿仍会保存，并重新在内联视图中出现；从窗口丢弃则会删除它
  - 已发送的回复现在会在你点击发送的瞬间显示在会话中
</Update>

<Update label="September 23, 2026" description="自定义 MCP 服务器">
  在集成页面连接你自己的远程 MCP 服务器（例如知识库），以便回复草稿可以连同你已在使用的内置工具一起从中查找信息。

  - 使用 OAuth 或 API 密钥添加服务器，随意命名，并可随时移除
  - 自定义服务器会显示在内置集成旁边，并带有清晰的标识
  - Plus 套餐提供此功能，每个邮箱账号最多 10 个自定义服务器
</Update>

<Update label="September 22, 2026" description="按发件人查看每周摘要">
  你的每周摘要会按发件人对冷邮件和已归档邮件进行分组，重复发件人会合并为一行，显示近期主题和计数，你还可以直接跳转到邮件，或在 Gmail 或 Outlook 中搜索该发件人。

  - 每个主题都会链接到你邮箱中的邮件
  - 发件人名称（以及"+N 更多"）会打开该发件人邮件的搜索
  - 摘要仅涵盖每周的冷邮件和归档动态，没有新内容时会跳过发送
</Update>

<Update label="September 17, 2026" description="即时本地搜索">
  邮件搜索会在你输入时立即给出结果：来自设备上已有邮件的匹配项会立刻显示，待完整的服务商搜索完成后更新，离线时也是如此。

  - 侧边栏将收件箱放在最前，并把草稿、已发送、已归档、已加星标、已定时、垃圾邮件和垃圾箱收进可折叠的"邮件"分组，需要时可随时使用这些视图
  - Gmail 的标签列表和邮件列表可见性设置会被遵循，你可以从标签的右键菜单中更改它们
  - 你开始撰写的新邮件会保存到邮箱的草稿箱，因此关闭撰写器后仍可在 Gmail 或 Outlook 中使用
</Update>

<Update label="September 16, 2026" description="斜杠片段">
  保存你常用的回复，输入 `/` 或使用片段按钮即可插入草稿；快捷方式可以自动填入收件人的姓名和邮箱，你可以在助手设置中管理它们。

  - 在聊天和撰写中说话代替打字：向编辑器口述，或与助手开始实时语音对话，完成后插入或发送转写内容
  - 按"今天下午""明天早上"或"下周一"等清晰的时间延迟，每个选项都会显示邮件何时返回
  - 会议简报先呈现简短的重点、决定和阻碍，随后是有用的参会人背景
  - 转发会显示所携带的文件，这些附件会随邮件一起在 Gmail 和 Outlook 中发送
</Update>

<Update label="September 15, 2026" description="高级搜索">
  按你的意图查找邮件：从搜索栏打开搜索选项，按发件人、收件人、主题、关键词、大小、日期、文件夹或标签以及附件进行筛选，然后使用仍可编辑的 Gmail 风格查询进行搜索。

  - 点击发送后的几秒内可撤销发送：取消投递并找回草稿
  - 查看已发送邮件被打开的时间，已发送中会显示"已打开"或"未打开"，并可在设置中按账号切换阅读状态
  - 在桌面应用中打开多个邮箱窗口，重新启动时可从上次离开的地方继续
</Update>

<Update label="September 12, 2026" description="分类的域名筛选">
  一步为某家公司的所有人创建分类：发件人条件现在可在 Gmail 和 Outlook 中匹配像 `@acme.com` 这样的整个域名。

  - 助手历史记录会按会话分组活动，深入查看时可展开邮件级别的详情
  - 当你批量处理过往邮件时，除非你开启回复草稿，否则不会生成
  - 新邮件与回复具有相同的撰写体验，包括稍后发送和提醒我
  - 在"你的分类"中拖动分类标签调整顺序
</Update>

<Update label="September 11, 2026" description="重要和其他">
  你的 Gmail 收件箱现在可以在独立分类中展示重要邮件，而不匹配其他分类的邮件会归入其他，这样筛选过的标签页能保持聚焦，又不会隐藏收件箱的其余部分。

  - 开启"重要"即可在已创建的分类旁浏览 Gmail 标记为优先的邮件
  - "其他"会接住不匹配任何已启用分类的收件箱会话
  - 禁用分类会将这些会话移回"其他"；"全部"始终提供完整的未筛选视图
</Update>

<Update label="September 10, 2026" description="分类收件箱库">
  分类收件箱不止是多标签筛选。你可以用"全部匹配"或"任意匹配"逻辑组合标签、类别、发件人、未读、星标和邮件时间，也可以从新库中选择预设并就地编辑分类。

  - 现成的"常规"和"应用"预设（包括 GitHub 和 Stripe），常用分类一键即得
  - AI 仍可根据自然语言建议分类，你可以在保存前编辑这些条件
  - 会话列表更易浏览：发件人名称更宽，并使用"过去 7 天"和"本月早些时候"代替每天一个标题
</Update>

<Update label="September 9, 2026" description="使用验证码登录">
  需要别人帮忙处理收件箱，又不想共享你的 Google 或 Microsoft 密码？在设置中开启邮箱验证码登录，对方即可使用发送到邮箱的一次性验证码登录。

  - 在设置中选择启用：默认关闭，关闭后会立即撤销所有有效的验证码会话
  - 验证码只能使用一次，几分钟内过期，并设有频率限制，防止被滥用
  - 基于验证码的会话始终受限：无法更改该设置、获取服务商凭证或创建不受限的移动端会话
</Update>

<Update label="September 8, 2026" description="多标签分类">
  创建同时覆盖多个标签的分类：描述你的需求，AI 会建议匹配的标签和名称，你也可以自行选择。滚动时合并结果始终保持最新优先。

  - 直接在邮件阅读器中回复日历邀请：是、否或也许
  - 将邮件侧边栏折叠为图标栏，或拖动边缘调整其大小
  - 从任何位置以对话框形式打开设置，包括从命令 K 打开
  - 会话列表按日期分组（今天、昨天及更早），让冗长的收件箱更易浏览
</Update>

<Update label="September 7, 2026" description="标记会话">
  无需离开邮件即可应用 Gmail 标签：按 L，选择现有标签或创建新标签，然后将其应用到当前会话或批量选择。

  - 侧边栏支持嵌套标签，像 Inbox Zero/Archived 这样的路径会清晰地嵌套在父级下
  - 展开会话预览，在打开会话前阅读更多摘要
  - 使用 F 或命令 K 转发，并在命令面板中找到更多阅读器操作
  - 发送、定时、提醒和附件的撰写快捷键，还可从命令 K 切换主题
</Update>

<Update label="September 6, 2026" description="稍后发送">
  发送前需要点时间？现在可以直接在你正在回复的会话中稍后发送回复，并设置提醒我，让跟进不会遗漏。

  - 回复草稿在导航和重新加载时都会保留，包括收件人、附件和格式
  - 离线或发送失败时可恢复，以便你在恢复联网后重试
  - Enter 打开回复，方向键在邮件间移动，工具栏可展开或折叠会话
  - 更简洁的阅读器和撰写器：日期在右侧，收件人和主题可编辑，选中文本时显示格式工具
</Update>

<Update label="September 3, 2026" description="你的每周邮件回顾">
  你的每周摘要回来了，并经过重新设计。每周一你都会收到一份清晰的回顾，说明为你归档了什么、哪些仍需回复，以及拦截了多少冷邮件。

  - Outlook 会话现在会直接在对话中显示你的回复草稿
  - 冷邮件拦截器对不请自来的推销更智能：具体且相关的邮件可以通过，模板化推销则会被拦截
  - 在阅读器中将邮件标记为垃圾邮件，并从操作菜单管理退订和自动归档
  - 在桌面端，更新就绪时会提示你，方便你在合适的时候重新加载
</Update>

<Update label="September 1, 2026" description="选择你的账号">
  有多个收件箱？现在你可以选择哪些已连接的账号显示在"所有账号"中，让你的合并邮箱只包含你关心的账号。

  - 从"所有账号"打开账号选择器并保存你的选择，该选择会跨会话保留
  - 新收件箱会获得为待回复、新闻邮件、营销、日历、收据等预先创建的分类
  - 在桌面端，Inbox Zero 默认打开邮件，让你更快进入收件箱
</Update>

<Update label="August 31, 2026" description="搜索你的邮件">
  无需离开 Inbox Zero 即可在邮箱中查找任何内容。邮件页面现在有真正的搜索框：输入查询并按下 Enter，结果会直接来自 Gmail 或 Outlook。

  - 搜索 Google 账号时，可使用 `from:` 和 `has:attachment` 等 Gmail 运算符
  - Outlook 搜索会返回整个邮箱中按相关度排序的匹配项
  - 按 Escape 或 X 按钮清除搜索；查询会保留在 URL 中，方便你分享或刷新视图
