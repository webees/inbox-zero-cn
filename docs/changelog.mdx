<Update label="2026年10月14日" description="从正确的地址回复">
  当有人写信到你用于发信的某个 Gmail 地址时，你的回复现在会从该地址发出，而不是你的默认地址。

  - 当你可以从多个地址发信时，会出现「发件人」选择器，新邮件中也是如此
  - 切换地址会带入该地址的 Gmail 签名，且不会改动你已写的内容
  - AI 草稿和自动回复也会使用匹配的地址
  - 发送新邮件后，确认提示会提供「查看」，让你无需离开当前位置即可打开它
</Update>

<Update label="2026年10月10日" description="待回复提醒">
  当有新邮件进入待回复时，手机会收到推送——无需打开应用，你就知道有哪些需要处理。

  - 当应用未聚焦时，桌面端的新邮件通知已恢复
  - 定时发送和撤销停留期间的发送不再让草稿滞留在「草稿」中
  - 撤销发送现在是更快的 10 秒窗口
</Update>

<Update label="2026年10月9日" description="更丰富的撰写编辑">
  撰写器现在直接编辑真实的邮件 HTML，因此在撰写和发送时，含表格、样式块和托管 Logo 的签名会保持完整——而不是被压平或锁定为只读块。

  - 即使没有 Google 通讯录访问权限，收件人建议也会从你设备上已有的邮件中提取
  - Slack 确认卡片会显示你完整的待发草稿（而非截断预览），对于非常长的消息，最后一张卡片上会有「发送」
  - 助手回复会跟随你正在回复的邮件语言，而不是你聊天所用的语言——除非你另有要求
  - 在稍后处理、删除、标记为垃圾邮件或移动后，阅读器会像归档那样前进到下一个会话
</Update>

<Update label="2026年10月8日" description="内联团队评论">
  团队评论现在就在会话本身中。按 M（或从「更多操作」/ 命令 K）打开它们，在消息下方内联讨论，并通过 @提及队友与他们分享该会话。

  - 未分享的会话保持安静——评论只有在你打开后才会出现，且仅当你的组织中有队友时
  - @提及不在该会话中的人时，会在你发送后与他分享该会话
  - 回复草稿会同步到你的邮箱，因此会出现在 Gmail、Outlook 以及你的其他设备上
  - 「与我共享」和「动态」位于你的账号菜单中，这些页面上的「会话」/「动态」标签页也更清晰
</Update>

<Update label="2026年10月7日" description="翻译会话">
  打开一个外语会话并点击翻译——Inbox Zero 会按需将消息转换为你的语言。在你主动请求之前不会运行任何操作，因此 AI 何时读取邮件由你掌控。

  - 从阅读器的更多菜单、命令面板（Cmd+K）或 Shift+T 进行翻译
  - 每条已翻译的消息都会显示其原始语言，并提供「显示原文」以切换回来
  - 已是你的语言的消息保持不变；再次翻译会切回原文，且不会再次调用 AI
  - 如果连接在回答中途断开，聊天回复会恢复；「停止」现在会真正取消本次运行
</Update>

<Update label="2026年10月6日" description="批量退订侧边栏">
  批量退订现在会在你点击某个发件人时打开侧边栏——统计、他们的邮件以及阅读器全都无需离开页面。更清晰的状态和触手可及的操作让你更快清理列表。

  - 状态分为待处理、全部发件人、已退订、已自动归档和已保留——除非你主动包含，否则待处理会隐藏没有退订链接的发件人
  - 当你只想停止接收未来的邮件、保留现有会话时，请关闭「退订时归档」
  - 退订、保留和归档位于页面底部的悬浮栏中
  - 很少阅读的发件人邮件与每周摘要外观一致，其中的行可直接链接到批量退订
</Update>

<Update label="2026年10月3日" description="附件预览">
  在会话中点击图片或 PDF 附件即可直接在 Inbox Zero 中打开——无需下载。先浏览文件，需要副本时再从对话框中下载。

  - 支持常见图片格式和 PDF
  - 你的账号时区现在会驱动会议简报、空闲时间和预约链接，日历设置中还提供了可搜索的城市选择器
  - 在批量退订中，滚动较长的发件人列表时表头会保持固定
</Update>

<Update label="2026年9月28日" description="连接常用应用">
  HubSpot、Salesforce、Slack 以及你已经在使用的其他应用现在可通过各自的登录方式连接——无需先注册 Pipedream 账号。连接后，你的助手可以在你起草和整理邮件时从这些应用中查询信息。

  - 开箱即用的应用有十一个：HubSpot、Salesforce、Airtable、Google Sheets、Slack、Asana、ClickUp、Jira、Zendesk、QuickBooks 和 Calendly
  - 每个连接都使用该应用自己的 OAuth 界面
  - 工具经过精心挑选且为只读，因此助手可以查询信息而不会更改你的数据
  - 集成列表更简洁，只显示应用名称
</Update>

<Update label="2026年9月27日" description="撤销发送">
  不小心点了发送？你的邮件会被保留 30 秒，让你可以撤销——即使你关闭了标签页或退出了应用。从提示中撤销，草稿会立刻回来。

  - 关闭标签页或退出应用不再会提前结束撤销窗口
  - 发送回复后，会话会跳到你的已发送邮件，方便你继续阅读
  - HubSpot、Salesforce、Slack 和 Airtable 等常用应用现在会在集成页面上单独显示为一行
</Update>

<Update label="2026年9月26日" description="弹出回复">
  把回复从会话中弹出到独立窗口，这样你在撰写时还能继续浏览其他邮件。使用「草稿到 …」旁边的按钮，或按 Cmd+Shift+P。

  - 适用于回复、转发和已保存的草稿——你的正文、收件人、附件和发送时间都会一并带过去
  - 关闭窗口会保留草稿，使其重新以内嵌方式出现；从窗口中丢弃则会删除它
  - 已发送的回复现在会在你点击发送的瞬间出现在会话中
</Update>

<Update label="2026年9月23日" description="自定义 MCP 服务器">
  从集成中连接你自己的远程 MCP 服务器——比如知识库——这样草稿回复就能在研究时结合它，以及你已经使用的内置工具。

  - 使用 OAuth 或 API 密钥添加服务器，随意命名，并可随时移除
  - 自定义服务器会显示在内置集成旁边，并带有清晰的徽章
  - 在 Plus 套餐中可用，每个邮箱账号最多可添加 10 个自定义服务器
</Update>

<Update label="2026年9月22日" description="按发件人汇集的每周摘要">
  你的每周摘要会按发件人对冷邮件和已归档邮件进行分组，让反复出现的发件人折叠为一行，并显示最近的主题和数量——你可以直接跳转到某封邮件，或在 Gmail 或 Outlook 中搜索该发件人。

  - 每个主题都链接到邮箱中的对应邮件
  - 发件人名称（以及「+N 更多」）会打开针对该发件人邮件的搜索
  - 摘要只关注每周的冷邮件和归档活动，没有新内容时则跳过发送
</Update>

<Update label="2026年9月17日" description="即时本地搜索">
  邮件搜索会在你输入时就开始给出结果——设备上已缓存的邮件匹配项会立即显示，随后在全量服务商搜索完成后更新，离线时也是如此。

  - 侧边栏将收件箱置于最前，并把草稿、已发送、已归档、已加星标、已计划、垃圾邮件和回收站收纳进可折叠的邮件分组，需要时可随时访问这些视图
  - 会遵循 Gmail 标签列表和邮件列表的可见性设置，你可以从标签的右键菜单中更改它们
  - 你开始撰写的新邮件会保存到邮箱的草稿中，因此关闭撰写器后它们在 Gmail 或 Outlook 中依然可用
</Update>

<Update label="2026年9月16日" description="斜杠片段">
  保存你经常使用的回复，输入 `/` 或使用片段按钮即可将其插入草稿——快捷片段可以为你填好收件人的姓名和邮箱，并在助手设置中管理。

  - 在聊天和撰写中可以说话而不用打字——对着编辑器口述，或与助手开始实时语音对话，完成后插入或发送转录文本
  - 用清晰的时段稍后提醒，例如今天下午、明天早上或下周一，每个都会显示邮件何时返回
  - 会议简报先呈现简短的优先事项、决策和阻碍，再给出有用的参会者背景
  - 转发会显示其携带的文件，这些附件会随邮件在 Gmail 和 Outlook 中一起发送
</Update>

<Update label="2026年9月15日" description="高级搜索">
  按你的本意查找邮件——从搜索栏打开搜索选项，按发件人、收件人、主题、关键词、大小、日期、文件夹或标签以及附件进行筛选，然后用仍可编辑的 Gmail 风格查询进行搜索。

  - 点击发送后有几秒钟的撤销发送时间——取消投递并取回草稿
  - 在已发送中通过「已打开」或「未打开」查看你的已发送邮件何时被打开，并在设置中按账号切换阅读状态
  - 在桌面应用中打开多个邮箱窗口，重新启动时从上次离开的地方继续
</Update>

<Update label="2026年9月12日" description="拆分的域名过滤">
  一步就能为公司里的所有人构建一个拆分——发件人条件现在可以匹配整个域名，比如 `@acme.com`，同时适用于 Gmail 和 Outlook。

  - 助手历史记录按会话对活动进行分组，深入查看时可展开到消息级别的详情
  - 当你批量处理历史邮件时，草稿回复默认关闭，除非你主动开启
  - 新邮件与回复拥有相同的撰写体验，包括稍后发送和提醒我
  - 在「你的拆分」中拖动拆分标签页，把它们调整为你想要的顺序
</Update>

<Update label="2026年9月11日" description="重要和其他">
  你的 Gmail 收件箱现在可以把「重要」邮件单独作为一个拆分呈现，而不匹配其他拆分的内容会归入「其他」——这样经过筛选的标签页能保持聚焦，又不会隐藏收件箱的其余部分。

  - 开启「重要」以浏览 Gmail 标记为优先级的邮件，与你已构建的拆分并列显示
  - 「其他」会收纳不匹配任何已启用拆分的收件箱会话
  - 停用某个拆分会把这些会话移回「其他」；「全部」始终可用于完整的未筛选视图
</Update>

<Update label="2026年9月10日" description="拆分收件箱库">
  拆分收件箱不止于多标签筛选。你可以用「全部匹配」或「任意匹配」逻辑组合标签、类别、发件人、未读、星标和邮件时间——或者从新库中挑选预设并就地编辑该拆分。

  - 现成的「常规」和「应用」预设（包括 GitHub 和 Stripe），让常用拆分一键可得
  - AI 仍能根据大白话建议拆分，你可以在保存前编辑这些条件
  - 会话列表更易浏览——发件人名称更宽，并用「最近 7 天」和「本月早些时候」取代了每一天的标题
</Update>

<Update label="2026年9月9日" description="使用验证码登录">
  需要有人帮忙处理你的收件箱，又不想分享你的 Google 或 Microsoft 密码？在设置中开启邮箱验证码登录，他们就能用发送到你邮箱的一次性验证码登录。

  - 在设置中选择启用——它默认关闭，关闭后会立即撤销所有有效的验证码会话
  - 验证码一次性使用，几分钟内过期，并有速率限制以防被滥用
  - 基于验证码的会话仍受限：它们无法更改该设置、拉取服务商凭据或创建不受限的移动端会话
</Update>

<Update label="2026年9月8日" description="多标签拆分">
  构建一个同时跨越多个标签的拆分——描述你想要的内容，AI 会建议匹配的标签和名称，或者你自己挑选。滚动时合并结果始终保持最新在前。

  - 直接在邮件阅读器中回复日历邀请：是、否或也许
  - 将邮件侧边栏折叠为图标栏，或拖动边缘调整其大小
  - 从任意位置以对话框方式打开设置——包括通过 Command K
  - 会话列表按日期分组（今天、昨天以及更早），让冗长的收件箱更易浏览
</Update>

<Update label="2026年9月7日" description="给会话打标签">
  无需离开邮件即可应用 Gmail 标签——按 L，选择一个现有标签或创建一个，然后将其应用到当前会话或批量选择。

  - 侧边栏中的嵌套标签，让 Inbox Zero/Archived 这样的路径整洁地嵌套在父标签下
  - 展开会话预览，在打开会话前阅读更多摘要内容
  - 用 F 或 Command K 转发，并在命令面板中发现更多阅读器操作
  - 针对发送、计划、提醒和附件的撰写快捷键——还可以从 Command K 切换主题
</Update>

<Update label="2026年9月6日" description="稍后发送">
  点发送前需要缓一缓？你现在可以安排在稍后发送回复，并设置「提醒我」以免跟进事项被遗漏——就在你正在回复的会话中进行。

  - 草稿回复在你导航和重新加载时保持存在，包括收件人、附件和格式
  - 离线或发送失败时邮件仍可恢复，让你可以在重新联网后重试
  - 按 Enter 打开回复，方向键在消息间移动，工具栏可展开或折叠会话
  - 更清爽的阅读器和撰写器：日期靠右，收件人和主题可编辑，选中文本时显示格式工具
</Update>

<Update label="2026年9月3日" description="你的邮件周报">
  你的每周摘要回来了——而且经过重新设计。每周一你都会收到一份清晰的回顾，包括为你归档了哪些邮件、还有哪些需要回复，以及拦截了多少封冷邮件。

  - Outlook 会话现在会直接在对话中显示你的草稿回复
  - 冷邮件拦截器对不请自来的外联更智能——具体、相关的邮件可以通过，而模板化的推销则被挡在外面
  - 从阅读器中把邮件标记为垃圾邮件，并从操作菜单中管理退订和自动归档
  - 在桌面端，你会看到更新何时就绪，方便你在合适的时机重新加载
</Update>

<Update label="2026年9月1日" description="选择你的账号">
  管理多个收件箱？你现在可以选择哪些已连接账号显示在「所有账号」中——这样你的合并邮箱只会包含你在意的账号。

  - 从「所有账号」打开账号选择器并保存你的选择；它会在各会话间保持
  - 新收件箱会获得现成的拆分：待回复、时事通讯、营销、日历、收据等
  - 在桌面端，Inbox Zero 默认打开邮件，让你更快进入收件箱
</Update>

<Update label="2026年8月31日" description="搜索你的邮件">
  无需离开 Inbox Zero 就能在邮箱中查找任何东西。邮件界面现在有了真正的搜索框——输入查询，按 Enter，结果直接来自 Gmail 或 Outlook。

  - 在搜索 Google 账号时使用 `from:` 和 `has:attachment` 等 Gmail 运算符
  - Outlook 搜索会返回整个邮箱中按相关性排序的匹配项
  - 用 Escape 或 X 按钮清除搜索；查询会保留在 URL 中，方便你分享或刷新视图
</Update>

<Update label="2026年8月28日" description="描述你的拆分">
  创建拆分收件箱就像输入你想要的内容一样简单。描述这个视图——比如「未读工作邮件」或「时事通讯」——Inbox Zero 会挑选匹配的过滤器并为你打开新标签页。

  - 会议记录器结束抢先体验——当会话中的每个人都参加了会议时，摘要可以帮助起草回复
  - 联系人建议现在也适用于抄送和密送，而不仅是收件人
  - 消息阅读器会显示发件人照片，并折叠引用的回复历史
  - 从会话菜单在 Gmail 或 Outlook 中打开任意对话
</Update>

<Update label="2026年8月26日" description="联系人建议">
  当你开始输入收件人时，Inbox Zero 现在会从你的 Gmail 和 Outlook 联系人中建议人选——这样你无需离开撰写界面就能选对人。

  - 输入时按姓名或邮箱搜索联系人
  - Outlook 建议使用你保存的联系人（如果需要授予访问权限，请重新连接账号）
  - 重复和无效的地址会被自动过滤掉
</Update>

<Update label="2026年8月25日" description="更丰富的撰写体验">
  在 Inbox Zero 中写邮件感觉更接近真正的邮件客户端。撰写会以一个安静的面板打开，带有格式、链接、列表、附件和内嵌图片——同时引用的回复和你的签名会得到保留。

  - 在「所有账号」中撰写时，选择使用哪个已连接账号发送
  - 需要更多空间时可将撰写器展开为全屏，或保持紧凑
  - 粘贴富文本和插入链接时不必与编辑器较劲
  - 不支持的布局会安全回退，复杂邮件不会被弄乱
</Update>

<Update label="2026年8月24日" description="本地优先的邮件">
  你的邮箱现在会在后台同步并保留在设备上，因此收件箱和未读可以即时打开——即使你处于离线状态或正在恢复联网。归档、删除、稍后提醒以及已读/未读更新都感觉即时，同时一切保持同步。

  - 右键点击侧边栏中的标签、类别和文件夹，即可重命名、更改颜色或删除
  - 用 ⌘A / Ctrl+A 选中当前视图中的所有会话
  - 「所有账号」保持缓存优先，因此页面刷新时合并收件箱依然响应迅速
</Update>

<Update label="2026年8月18日" description="处处更迅捷">
  Inbox Zero 在桌面端和网页端都感觉更快了。桌面应用会即时重新打开并从你上次离开的地方继续，悬停邮件会预热它，让打开感觉即时。

  - 在 Mac 上，关闭窗口会隐藏应用而不是退出，因此从 Dock 重新打开是即时的
