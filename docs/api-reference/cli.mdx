当你需要为脚本、机器人或本地自动化提供一个围绕公开 API 的轻量封装时，可以使用 Inbox Zero API CLI。

该包以 `@inbox-zero/api` 发布到 npm，可执行文件名为 `inbox-zero-api`。

## 使用 npx 运行

需要 Node.js `18+`。

```bash
npx @inbox-zero/api --help
```

你也可以全局安装它：

```bash
npm install -g @inbox-zero/api
```

## 配置访问

CLI 按以下顺序读取配置：

1. 命令标志
2. 环境变量
3. `~/.inbox-zero-api/config.json`

支持的环境变量：

- `INBOX_ZERO_API_KEY`
- `INBOX_ZERO_BASE_URL`，用于自托管或自定义 API 部署

示例：

```bash
inbox-zero-api rules list
```

`base-url` 是可选的。CLI 默认使用 `https://www.getinboxzero.com`，只有自托管或自定义部署才需要覆盖它。

在运行命令前，请在 shell 或密钥管理器中设置 `INBOX_ZERO_API_KEY`。避免将 API 密钥作为 CLI 参数传入，因为它们可能泄漏到 shell 历史和进程列表中。

## 常用命令

列出规则：

```bash
inbox-zero-api rules list
inbox-zero-api rules list --json
```

获取一条规则：

```bash
inbox-zero-api rules get rule_123 --json
```

从 JSON 创建规则：

```bash
inbox-zero-api rules create --file rule.json
cat rule.json | inbox-zero-api rules create --file -
```

从 JSON 更新规则：

```bash
cat rule.json | inbox-zero-api rules update rule_123 --file -
```

删除规则：

```bash
inbox-zero-api rules delete rule_123
```

读取统计数据：

```bash
inbox-zero-api stats by-period --period week --json
inbox-zero-api stats response-time --json
```

退订某个发件人：

```bash
inbox-zero-api senders unsubscribe news@example.com
inbox-zero-api senders unsubscribe news@example.com --json
```

获取实时 OpenAPI 文档：

```bash
inbox-zero-api openapi --json
```

对于机器人，请优先使用 `--json`，以便输出稳定且可机器读取。
